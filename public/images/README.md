# Image Assets Needed

Place the following images in this directory (`/public/images/`):

## Required Images:

1. **hero-stairs.jpg**
   - Large architectural image of stairs
   - Used in hero section grid
   - Recommended size: 800x1000px minimum
   - Format: JPG (optimized for web)

2. **hero-pool.jpg**
   - Large architectural image of pool/water feature
   - Used in hero section grid
   - Recommended size: 800x1000px minimum
   - Format: JPG (optimized for web)

3. **hero-small.jpg**
   - Smaller architectural detail image
   - Used in hero section grid
   - Recommended size: 400x500px minimum
   - Format: JPG (optimized for web)

4. **logo.svg**
   - Westie company logo
   - Used in header and favicon
   - Format: SVG (vector)
   - Should be clean, minimal design

## Usage in Code:

```jsx
// Images will be referenced as:
<img src="/images/hero-stairs.jpg" alt="Architectural stairs" />
<img src="/images/hero-pool.jpg" alt="Modern pool design" />
<img src="/images/hero-small.jpg" alt="Design detail" />
<img src="/logo.svg" alt="Westie logo" />
```

## Notes:
- All images should be optimized for web (compressed)
- Use descriptive alt text for accessibility
- SVG logo should have a transparent background
- Images should maintain high quality while keeping file sizes reasonable
- Consider using WebP format for even better performance
